# Simple Password checker
This is a beginner-level Python project.
The program checks whether a password is strong or weak based on:
- Minimum length of 8 characters
- At least one number in the password

## How It Works
- Takes password input
- Checks its length
- Checks if it contains a number
- Prints the result

## Example
1. Enter your password:<br>
hello123<br>
Output:<br>
Strong Password
-----------------------
2. Enter your password:<br>
hello<br>
Output:<br>
Weak Password

- Python
- Loops
- Conditional statements
- String methods
